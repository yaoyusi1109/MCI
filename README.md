# MCI

Operations research readings and resources for mass casualty incidents, emergency evacuation, ambulance dispatch, and healthcare resource allocation.

The [`reference/`](reference/) folder contains 13 unique full-text articles, source links, and download records. See the [reference index](reference/README.md) for the numbered reading list and file details.

The [`models/`](models/) folder contains a course-style [Gurobi notebook](models/mci_ambulance.ipynb), a runnable Python script, and the [mathematical formulation](models/formulation.md) for minimizing patient waiting at MCI sites. The current example uses synthetic data.
